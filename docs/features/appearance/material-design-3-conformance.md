# Material Design 3 conformance

## Behavior

The design reference (`design/yt-dlp Studio.dc.html`) is authored against Material Design 3
tokens, typography, shape, elevation, and motion. The intended real application should conform
fully, with no legacy or ad-hoc UI elements, and should ship a per-element appearance editor
(installed-font typography, an infinite color picker with a color-space translator, named
presets, export/import) as described in `design/HANDOFF.md`'s house-rules section.
