Documentation

yt-dlp Studio is a Windows desktop application built with Electron and Material Design components. This page covers the parts of the project that matter most before your first install: what's bundled, why the installer is unsigned, and how to build it yourself.

No release has been published yet. Everything on this page describes how the project is built and how it will behave once a build ships — check the releases page for the current state.

Bundled binaries

yt-dlp Studio bundles two external tools inside its own installer so nothing has to be installed separately: yt-dlp, built from a pinned commit of the upstream yt-dlp source, and ffmpeg, used for merging separate video and audio streams and for format conversion. Both ship as part of the application package rather than being downloaded at first run, so the app works fully offline once installed.

Pinning the yt-dlp source means a given release of yt-dlp Studio always bundles a known, reproducible version of the downloader — the release notes for each build will record exactly which upstream commit was used.

The unsigned installer

This project does not use code signing. Windows SmartScreen will show an "unknown publisher" warning the first time you run a new installer or update — this is expected for any unsigned application and is not, by itself, evidence that a download has been tampered with.

What you should still do before trusting a download: fetch it only from the project's own GitHub Releases page, never from a third-party mirror; confirm the release was published from this repository; and, if the release notes publish a checksum, verify the downloaded file against it before running the installer.

Building from source

If you would rather not wait for a signed or even an unsigned release, the project builds from source with ordinary Node.js and Electron tooling:

git clone --recurse-submodules https://github.com/Ding-Ding-Projects/material-ytdlp
cd material-ytdlp/app
npm install
npm run build
npm run dist

npm run dist produces a Squirrel.Windows installer under the app package's build output. Because vendor/yt-dlp is a git submodule, remember to clone with --recurse-submodules or run git submodule update --init afterward, or the bundled yt-dlp source will be an empty directory.

File converter

The desktop app includes a file converter that uses the bundled ffmpeg to change a downloaded file's container or codec after the fact — for example, pulling audio out of a video file, or converting between common video containers. Conversion runs entirely locally; nothing is uploaded anywhere.

Local model suite

yt-dlp Studio can optionally manage a locally installed Ollama runtime for on-device model features. This is opt-in: the app does not install or require Ollama to perform ordinary downloads, and no model data or prompt ever leaves your machine through this feature.

Getting help

Questions, bug reports, and feature requests belong on the issue tracker in the source repository. Please don't file yt-dlp download-engine bugs there — those belong upstream, on the yt-dlp issue tracker itself.
