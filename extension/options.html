yt-dlp Studio Companion

This extension does one thing: it hands the page you're on to yt-dlp Studio, the desktop app, over the ytdlp-studio:// link scheme. Nothing here is uploaded anywhere, and this options page is the extension's entire settings surface.

Behaviour

Confirm before sending a link
Requires a second click in the popup before the page is handed to yt-dlp Studio. Off by default.

Not installed yet?

Open the install guide ↗ — three steps, no Chrome Web Store listing. yt-dlp Studio is permanently unsigned and does not use a Web Store extension key, so this is the closest thing to one-click installation this project can ship.
