Landed since this list was written

0 of 6 ticked

Not ticked above because none has been exercised in the packaged application yet, which is the bar this project uses for a tick. All are implemented and type-check clean.

  • External-editor handoffDetects a real editor: code on PATH, then known install paths, then the OS default; reports which route worked or fails out loud.
  • Application-mark customizationVerifies real image bytes and dimensions before writing; display only — never touches data directory, installer identity or update feed.
  • Support ticketsLocal only. Currently broken: it collects input with window.prompt(), which Electron does not implement.
  • yt-dlp informational probesSubtitles, thumbnails, URL probe, and a real extractor count — 1753, not the 1908 the design showed.
  • Config file read/write/validateAtomic writes, a real parse rather than a blank check, across the five standard locations.
  • Download-archive read and compactionOperates on the real archive file.
