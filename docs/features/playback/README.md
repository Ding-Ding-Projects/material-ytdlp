# Playback

Articles covering the in-app media player: a real queue the user can add to from a completed
download or a pasted link, and play — video or audio — without opening a separate file or app,
while downloads continue in the background.

- [Media player and queue](media-player.md) — the queue itself, transport controls, and how a
  completed download plays.
- [Remote link playback](remote-link-playback.md) — how a pasted link is turned into a playable
  stream, the custom protocol that serves it, and the format-selector investigation (including a
  dead end) behind the current design.
