# App mark

`mark.svg` is original artwork authored for this project (yt-dlp Studio). It is
not copied, traced, or derived from the yt-dlp logo, YouTube's branding, or any
other organisation's mark.

Palette (from the app's Material Design 3 dark teal theme):

- Background: `#0f1414`
- Primary: `#82d5cc`
- On-primary: `#003733`

Run `node scripts/make-icons.mjs` from the repository root to regenerate the
packaged icon assets in `app/build/` from this source file.
