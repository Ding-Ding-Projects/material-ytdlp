Why Windows will warn you

The installer is unsigned on purpose. Here is exactly what that means and what it doesn't.

Code signing costs money on an ongoing basis, and this project does not use it. That means the very first time you run a new build of the installer, Windows SmartScreen will interrupt with a blue "Windows protected your PC" screen naming an unrecognized app or unknown publisher.

What this warning is

SmartScreen's reputation check for a binary it has not seen enough copies of yet. It fires for any unsigned installer, regardless of what the installer actually does — it is not a virus scan result and not evidence of anything malicious.

What this warning is not

Not a sign of a bad or tampered download by itself. It appears identically for every fresh unsigned build this project ever ships, including ones built straight from this repository's own source.

How to proceed

Click "More info", then "Run anyway" — but only after checking you downloaded the installer from the GitHub Releases page linked above, not from a third-party mirror.

Verifying the file

Every release's notes carry the SHA-256 of the installer and of the bundled binaries, so the download can be checked against a known-good hash before you run it.

What's inside the installer

Nothing to install separately — this is the whole point of bundling.

  • yt-dlp Studio itself — the Electron application, Material Design interface, and its main-process download engine.
  • A compiled yt-dlp.exe — built with PyInstaller from the pinned vendor/yt-dlp submodule at build time, not downloaded as a prebuilt binary.
  • A compiled ffmpeg — built from the pinned vendor/ffmpeg submodule as an LGPL build (--enable-gpl is never passed; --enable-nonfree never will be). See why on the building page.

No Python interpreter, no separate ffmpeg download, no PATH configuration. The smoke test that gates every release asserts all three bundled binaries actually run.

System requirements

Windows only, for now. See the roadmap for other platforms.

Operating system

Windows only. This is the project's current, deliberate delivery scope — there is no macOS or Linux build.

Installer

Squirrel.Windows (Setup.exe), which also gives the app Chrome-style background updates once automatic updates are built — see the roadmap.

Network access

Only used by yt-dlp itself when you start a download. The app makes zero requests on its own — asserted by the smoke test on every release.

Disk space

The bundled yt-dlp and ffmpeg builds add real size to the installer compared with a script-only tool. See the FAQ for why that trade was made.
