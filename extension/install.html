Getting the yt-dlp Studio Companion working

Since this extension isn't on the Chrome Web Store — this project never generates or stores a signing key, permanently — installing it takes three manual steps instead of one click. If you're reading this page, the extension is already loaded; keep it for reference or send it to whoever needs it next.

1

Open your browser's extensions page

Neither Chrome nor Edge lets another app open this page for you — paste one of these into the address bar yourself.

chrome://extensions  or  edge://extensions
2

Turn on Developer mode

It's a toggle in the top-right corner of that page. Unpacked extensions (extensions loaded from a folder instead of the Web Store) only show up once it's on.

3

Click "Load unpacked" and choose this extension's folder

yt-dlp Studio's own Browser extension screen (open it with Ctrl+Shift+F and search "extension") shows the exact folder path on this computer, with buttons to open it in Explorer or copy the path.

The first time you click "Send to yt-dlp Studio", Windows will ask which app should open ytdlp-studio:// links. Choose yt-dlp Studio and tick "always allow" so it only asks once. If nothing asks at all, yt-dlp Studio probably isn't installed yet — grab the installer from the app's own release page and run it first.
