Wrap yt-dlp in a cockpit you can actually see.

yt-dlp Studio is a Material Design desktop app that sits on top of yt-dlp: pick a URL, plan the command visually, and run it — with yt-dlp and ffmpeg bundled inside the installer, so there is nothing else to set up.

A downloader that stays out of your way.

yt-dlp does the work. yt-dlp Studio gives it a Material Design surface — so the options you use often are visible, and the ones you rarely touch don't clutter the screen.

Bundled, not borrowed

yt-dlp and ffmpeg ship inside the installer, built from pinned upstream source. No separate download, no PATH configuration, no version mismatch to chase.

A command you can read

Every choice in the planner writes into a real, visible yt-dlp command line as you make it — copy it, edit it by hand, or just let the app run it for you.

Material Design throughout

Light and dark themes, keyboard-accessible controls, and a layout that holds together from a phone-width preview up to a full desktop window.

Getting started

Start simple. Grow into the details.

A first download needs one field. Everything else — subtitle handling, output templates, format selection — is there when you want it, not before.

yt-dlp <media URL>
  1. 1 Paste a URLDrop the link into the planner or run yt-dlp Studio's command line directly.
  2. 2 Choose a preferenceBest quality, audio only, or the smallest file — the planner fills in the right flags.
  3. 3 Run or copy the draftUse the app's own runner, or copy the composed command into any terminal.

The desktop app's file converter turns a finished download into another container or codec using the bundled ffmpeg — no separate ffmpeg install, and no upload anywhere. See the file converter documentation for the full list of supported formats.

The desktop app's local model suite manages an installed Ollama runtime entirely on your machine — no cloud account, no data leaving the device. See the local model suite documentation for setup.

Language modes, theme, density, and every other appearance setting in the desktop app persist locally and never leave your machine. See the documentation index for the settings reference.

Short answers. The documentation goes deeper on each of these.

Is this the official yt-dlp project?
No. yt-dlp Studio is an independent desktop application that wraps the open-source yt-dlp project and bundles it for convenience. All credit for the download engine itself belongs to the yt-dlp maintainers and contributors; this project is not affiliated with or endorsed by them.
Why does Windows warn about an unknown publisher?
The installer is deliberately unsigned. Code signing costs money and this project does not use it. SmartScreen will show an unknown-publisher prompt the first time you run a new build — that's expected, not evidence of tampering. See the installation guide for what to check before you trust a download.
Is there a release yet?
Not yet published. The "Download for Windows" and "View releases" links on this site both go to the project's GitHub Releases page, which will list the current build once one ships — nothing on this page invents a version number or a file size ahead of that.
